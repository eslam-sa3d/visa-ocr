# API examples and sample data

Generated by `tools/make_samples.py` from the running service. All people are fictional and all numbers are made up.

## 1. Upload a document

Send 1 to 4 JPEG or PNG images (for example the passport data page). The call returns immediately with a job.

```bash
curl -X POST https://ocr.internal.example/v1/documents/extract \
  -H 'X-Correlation-ID: portal-req-0001' \
  -F 'files=@data-page.jpg;type=image/jpeg' \
  -F 'doc_type_hint=passport'

# Poll for the result:
curl https://ocr.internal.example/v1/jobs/7f3c2a9e1b4d4c6a8e5f0b1d2c3a4b5e
```

Response `202 Accepted`:

```json
{
  "jobId": "7f3c2a9e1b4d4c6a8e5f0b1d2c3a4b5e",
  "status": "queued",
  "correlationId": "portal-req-0001"
}
```

## 4. Failures

No MRZ found in the image (job status `failed`):

```json
{
  "jobId": "7f3c2a9e1b4d4c6a8e5f0b1d2c3a4b5e",
  "correlationId": "portal-req-0001",
  "status": "failed",
  "createdAt": "2026-11-09T09:52:14.512345+00:00",
  "result": null,
  "error": {
    "code": "mrz_not_found",
    "message": "No MRZ found. Ask the applicant to retake the photo."
  }
}
```

Rejected upload (HTTP 415):

```json
{
  "detail": {
    "code": "bad_type",
    "message": "Only JPEG and PNG are accepted"
  }
}
```

## 5. Parse MRZ text you already have

`POST /v1/mrz/parse` (no OCR involved), shown with a Schengen visa sticker:

```json
{
  "lines": [
    "V<FRASPECIMEN<<NORA<SAMPLE<<<<<<<<<<<<<<<<<<",
    "VS00000012SAU9003152F2705125<<<<<<<<<<<<<<<<"
  ]
}
```

Response `200 OK`:

```json
{
  "document": {
    "format": "MRVA",
    "kind": "visa",
    "typeCode": "V",
    "issuingState": "FRA",
```

|---|---|---|

| `passport_gbr` | Passport, United Kingdom (synthetic, born 2001) | TD3 |
